# Most likely not an IEC 104 implementation

This project is a non-conformant and incomplete implementation of IEC104. It
was developed as a clean slate impl from packet dumps after I had done a
similar implementation in python.

I aim to at least implement the parsers and data as a sans-io part, with types,
and after that some ideas are:

- IO/sync part of a server?
- Async part?
- Python bindings/lib so I can have fun?
